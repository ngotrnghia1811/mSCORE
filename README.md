# Skill-based Reasoning Evaluation for Multi-lingual Commonsense Question Answering

This project aims to evaluate skill-based reasoning in multi-lingual commonsense question answering using large language models (LLMs).

## Project Structure

- `src/`: Contains the source code for the project.
- `tests/`: Contains test cases and scripts.
- `requirements.txt`: Lists the Python dependencies for the project.

## Getting Started

1. Clone the repository.
2. Install the dependencies using `pip install -r requirements.txt`.
3. Run the tests to ensure everything is set up correctly.
